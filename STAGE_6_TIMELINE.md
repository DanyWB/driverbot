# Этап 6. Timeline / шахматка занятости

Дата закрытия: 2026-07-21. Быстрое создание брони на сетке добавлено 2026-07-22.

Статус: выполнен.

## 1. Результат

В Laravel-админке реализован рабочий календарь занятости техники по адресу
`GET /timeline`. Экран использует тот же `vehicle_occupancies`, что и сервисы
бронирования и обслуживания, поэтому не создает отдельную модель доступности и не
дублирует правила блокировки.

Timeline показывает:

- технику строками, даты календарными колонками;
- `pending`, `approved`, `active` и `maintenance` отдельными системными цветами;
- блоки, продолжающиеся за левой или правой границей выбранного периода;
- количество показанной, полностью свободной и занятой техники;
- активную дату в timezone `Asia/Bangkok`.

Drag-and-drop и изменение брони непосредственно на сетке намеренно не реализованы.
Все изменения проходят через карточку и существующие Laravel-сервисы.

## 2. Серверный контракт

`TimelineRequest` задает текущий календарный месяц, если даты не переданы, и
ограничивает один запрос 93 днями. В БД загружаются только occupancy, пересекающие
выбранный диапазон и имеющие `blocks_availability = true`.

Поддержаны серверные фильтры:

- тип техники;
- категория;
- конкретная техника;
- active/visible/hidden/inactive/all;
- статус занятости;
- только полностью свободная техника.

Запрос выполняется двумя ограниченными выборками: техника с категорией и occupancy с
бронью/клиентом. N+1-запросов на строки календаря нет. Presenter возвращает готовые
`start_index`, `span_days` и признаки продолжения блока за границами периода.
При фильтре по статусу UI показывает только подходящие блоки, но отдельные
`blocked_ranges` содержат все реальные пересечения. Поэтому скрытый фильтром статус
не превращает занятый день в доступный для быстрого создания.

## 3. Рабочие сценарии

- Кнопки предыдущего/следующего периода двигают полный месяц либо текущую длину
  произвольного диапазона.
- `Today` возвращает к текущему месяцу по Bangkok time.
- Нажатие на бронь открывает ее операционную карточку.
- Первый клик по свободной ячейке активной техники выбирает начало аренды; второй клик
  в той же строке выбирает завершение. Период подсвечивается непосредственно на сетке.
- Если между выбранными датами есть занятый день, боковая форма не открывается и
  администратор получает понятную ошибку.
- После выбора свободного периода справа открывается форма быстрого создания: новый
  или существующий клиент, время, источник, начальный статус, автоматический расчет,
  заметки и необязательная ручная итоговая цена.
- После сохранения календарь обновляется в том же периоде и с теми же фильтрами.
- Возврат из создания или карточки восстанавливает период и все примененные фильтры.
- Статусное действие, изменение дат или цены в открытой из timeline карточке также
  сохраняет этот контекст.

`return_to` принимается только как относительный URL с путем `/timeline`. Схемы,
host, credentials и fragment отклоняются, поэтому параметр нельзя использовать как
open redirect.

## 4. Надежность занятости

Клиентская проверка выбранного диапазона является только снимком состояния. При сохранении ручной брони
Laravel повторно блокирует технику и проверяет пересечение внутри транзакции. Если
ячейку уже занял другой запрос, новая бронь отклоняется, а введенные данные остаются
в открытой боковой форме.

Во время тестирования найден и устранен пограничный дефект локального SQLite:
date-поля occupancy сериализовались как `YYYY-MM-DD 00:00:00`, из-за чего сравнение
однодневной брони с той же датой могло не увидеть конфликт. `DateOnlyCast` теперь
хранит `starts_on/ends_on` строго как `YYYY-MM-DD`; поведение SQLite и PostgreSQL
согласовано.

## 5. Интерфейс

Сетка имеет фиксированную ширину колонки техники и дня, внутреннюю горизонтальную и
вертикальную прокрутку, sticky header и sticky колонку техники. Paint containment не
дает прокрученным sticky-строкам рисоваться поверх фильтров.

Начальная дата выделяется amber-цветом, допустимый предварительный диапазон — зеленым,
а диапазон с пересечением — красным. Выбор можно сбросить кнопкой или клавишей
`Escape`. Неактивная техника не допускает создание брони.

Проверены viewport:

- desktop `1440x1000`;
- tablet `1024x768`;
- mobile `390x844`.

На всех размерах документ не получает горизонтальную прокрутку; широкая сетка
прокручивается только внутри timeline. На tablet/mobile элементы управления
переносятся без пересечений, названия техники обрезаются внутри стабильной колонки.

- безопасного сохранения `return_to`;
- предзаполнения ручной брони;
- возврата быстрого создания в тот же timeline;
- повторной серверной проверки занятого параллельно слота.

Финальные результаты:

- единый `npm run precheck`: 120 Laravel tests, 117 passed, 3 PostgreSQL-only
  skipped в SQLite-профиле, 648 assertions;
- отдельный PostgreSQL-набор: 3/3 tests, включая exclusion constraint и
  multi-process race;
- ESLint, Prettier, Vue TypeScript, PHPStan и production Vite build пройдены;
- browser QA завершен без console/page errors.
