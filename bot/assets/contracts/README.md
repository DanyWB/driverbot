Разрешение 2324 × 3297. Исходные `agreement-{ru,en,ua}.png` сохранены без изменений.

Бот отправляет соответствующий файл из `opaque/` документом, без сжатия Telegram. В этих RGB-копиях прозрачность исходника математически наложена на белый фон: `round((color × alpha + 255 × (255 − alpha)) / 255)`. Размер, непрозрачные пиксели, текст и метаданные разрешения сохранены. Масштабирование, распознавание и перерисовка не применяются.

Пересоздание из корня репозитория: `node bot/scripts/prepare-contracts.js`.
Проверка без записи: `node bot/scripts/prepare-contracts.js --check`.
Скрипт использует только стандартную библиотеку Node.js и не запускает бота.

По подтверждённому требованию от 29 октября 2026 отправляется только первая страница для каждого языка. Маркировка 1/2 остаётся частью исходного изображения; вторая страница в этот выпуск не входит.
